# 📸 MessageImage — メッセージのスクリーンショット

Discordのメッセージを奇妙な画像(?)に変えます。 Upvoteboard 機能をサポートします。メッセージが十分な賛成票を受け取ると、ハイライトを保存するために自動的にスクリーンショットが撮影され、指定されたチャンネルに送信されます。

|コマンド |説明 |
| --- | --- |
| `y!ss` (メッセージへの返信) |指定されたメッセージのスクリーンショット |
| `Screenshot Generator` (メッセージ コンテキスト メニュー) |指定されたメッセージのスクリーンショット |
| `Terrible Make it a Quote` (メッセージ コンテキスト メニュー) | Make it a Quote の画像を模倣していますが、さらに悪くなります。
| `What is this guy talking about` (メッセージ コンテキスト メニュー) |メッセージのスクリーンショットを撮り、その下に吹き出し画像をランダムに追加します。
| `/高評価ボード` | Upvoteboard チャンネルを設定する |
