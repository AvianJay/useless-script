# 🐾 petpet — PetPet アニメーション エンターテイメント

任意のユーザーのアバターから撫でアニメーションGIFを生成！スラッシュ コマンドと右クリックのコンテキスト メニュー アクションの両方をサポートし、pat および pat 受信数を追跡します。

|コマンド |説明 |
| --- | --- |
| `/ペットペット` |指定したユーザーの PetPet アニメーションを生成する |
|ユーザーを右クリック (長押し) → [アプリ] → `PetPet` |ユーザー上でコンテキスト メニューを直接使用する |
| `/petpet統計` | PetPet パットの統計を表示 |
