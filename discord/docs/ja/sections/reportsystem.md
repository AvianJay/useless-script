# 🚨 ReportSystem — レポート システム

ユーザーは、右クリックのコンテキスト メニューからルールに違反するメッセージを報告できます。このシステムは AI を使用してメッセージの重大度 (レベル 0 ～ 5) を自動的に判断し、サーバーのルールに基づいて懲戒処分を提案します。組み込みのクールダウンとブラックリスト メカニズムにより、悪用を防止します。

## 使用方法

> **報告方法:** メッセージを **右クリック** (モバイルでは長押し) → **アプリ** → **メッセージを報告**し、報告の理由を入力して送信します。システムは自動的に管理者に通知し、AI レビューをトリガーします。

## 管理者設定コマンド (/report) 管理者

|コマンド |説明 |
| --- | --- |
| `/通報 設定` |さまざまなレポート システム設定を表示または変更する |
| `/通報 拒否ロール` |レポートのブラックリストのロールを管理 (追加/削除/表示) |
| `/通報 サーバールール設定` | AI レビューのベースとなるサーバー ルールを設定します。

## 構成可能なオプション

|設定 |説明 |デフォルト |
| --- | --- | --- |
| `檢舉通知頻道` |報告記録とAI判定結果を受け取るチャンネル |未設定 |
| `處分通知頻道` |執行措置の発表が投稿されるチャンネル |未設定 |
| `檢舉回覆訊息` |レポート提出後に報告者に表示される確認メッセージ |ご報告ありがとうございます... |
| `檢舉頻率限制` |同じユーザーからの 2 つのレポート間のクールダウン (秒) | 300秒 |
| `檢舉通知訊息` |通知チャンネル内の追加の @言及されたロールまたはコンテンツ | @管理人 |

## AI レビュー プロセス

レポートを受信すると、システムは次のプロセスを自動的に実行します。

> 1. 報告されたメッセージの内容と添付ファイルを抽出する
> 2. ユーザーの最新 10 件の履歴メッセージをコンテキストとして収集する
> 3. AI にサーバー ルールに基づいて違反の重大度 (0 ～ 5) を決定させる
> 4. AI が推論付きで推奨アクション (タイムアウト / キック / 禁止) を提供します
> 5. 管理者はボタンをクリックして AI の提案を直接実行することも、手動でアクションを選択することもできます

## 管理者アクション ボタン

レポート通知がレポート チャンネルに到達すると、管理者は次のアクション ボタンを使用できるようになります。

|ボタン |説明 |
| --- | --- |
| `執行 AI 建議處置` | AI が提案したアクションをワンクリックで実行 |
| `封鎖` |報告されたユーザーを手動で禁止します (削除期間と禁止期間は設定可能) |
| `踢出` |報告されたユーザーを手動でキックする |
| `禁言` |報告されたユーザーを手動でタイムアウトします (期間は構成可能) |
| `查看前10則訊息` |そのチャンネルで報告されたユーザーのメッセージ履歴を表示する |
| `拔除檢舉人檢舉權限` |悪意のある報告が行われた場合は、報告者の報告権限を取り消します。
| `拒絕檢舉` |この報告を拒否し、報告者に DM 通知を送信します。

## ブラックリストのメカニズム

> **レポート ブラックリスト:** 管理者は `/通報 拒否ロール` を使用して「レポート ブラックリスト ロール」を設定できます。このロールを持つメンバーはレポートを送信できません。特定のユーザーによるレポート機能の悪用を防ぐのに役立ちます。
