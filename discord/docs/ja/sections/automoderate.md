# 🤖 AutoModerate — 自動モデレーション管理者の自動化

アンチスパム、アンチレイド、ユーザーがインストールしたアプリからのスパムに対する保護、招待リンクの検出、詐欺トラップ、過剰な絵文字の検出、罰回避の検出、その他のさまざまな自動モデレーション機能を含む、完全に自動化されたサーバー保護システム。

|コマンド |説明 |
| --- | --- |
| `/自動モデレーション クイック設定` |自動モデレーション ルールをすばやく構成する |

> **機能リスト:** スパム対策、レイド対策、UIスパム対策、招待リンク対策、ScamTrap、過剰な絵文字検出、罰回避検出、AutoMod イベント統合。 Anti-Invite Link は「このサーバーのリンクを許可する」設定をサポートしており、外部サーバーへの招待のみをブロックできます。詳細な設定は、[Web パネル](/panel/) から行うことができます。
