# 🔧 UtilCommands — ユーティリティ コマンド

ボット情報、サーバー情報、遅延テスト、変更ログ、チュートリアルなどを含む、一般的に使用されるユーティリティ コマンドのコレクション。

|コマンド |説明 |
| --- | --- |
| `/情報 ヘルプ` |使用可能なすべてのコマンドを表示 |
| `/情報 ボット` |詳細なボット情報を表示 |
| `/情報 ピング` |ボットの遅延をテストする |
| `/情報 ユーザー` |指定したユーザーの情報を表示する |
| `/情報 サーバー` |現在のサーバーの情報を表示 |
| `/情報 アバター` |ユーザーのアバターを表示 |
| `/情報 バナー` |ユーザーのバナーを表示 |
| `/情報 メンション` |コマンドの記述形式を取得する |
| `/情報 変更履歴` |変更ログを表示 |
| `/情報 コミット` |最近の Git コミット履歴を表示する |
| `/情報 チュートリアル` |インタラクティブな入門チュートリアル |
| `/ニトロ` | Nitro ギフトリンク保護 |
