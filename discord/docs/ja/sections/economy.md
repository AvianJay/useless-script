# 💰 経済 — 経済システム

完全な二重通貨仮想経済システム。ボットのグローバル通貨はサーバー間で機能しますが、サーバー コインは現在のサーバーに限定されます。日次/時間別の報酬、ショップの売買、送金、為替レートのメカニズム、インフレ/デフレ モデル、小切手システムなどが含まれます。

|コマンド |説明 |
| --- | --- |
| `/経済 デイリー` |毎日の報酬を受け取りましょう |
| `/経済 毎時` |時間ごとの報酬を請求 |
| `/経済 残高` |残高を確認する |
| `/経済 購入` |ショップからアイテムを購入する |
| `/経済 売却` |アイテムを販売する |
| `/経済 取引` |他のユーザーとの取引/譲渡 |
| `/経済 履歴` |取引履歴の表示 |
| `/経済管理` |管理者経済管理ツール |

> **不正行為防止メカニズム:** システムは管理者によって注入された通貨を追跡し、経済のバランスを保つために上限を適用します。
