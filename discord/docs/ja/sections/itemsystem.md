# 🎒 ItemSystem — アイテムシステム

サーバースコープのインベントリとグローバルインベントリの両方をサポートする仮想アイテムシステム。各サーバーはカスタム アイテムを作成でき、アイテムを使用すると特定の機能をトリガーできます。アイテムをドロップして他のユーザーが拾ったり、他のユーザーにプレゼントしたりすることができます。

## 一般ユーザーコマンド (/item)

|コマンド |説明 |
| --- | --- |
| `/アイテム 一覧` |所有するアイテムを表示します (オプションでサーバー/グローバルにスコープを設定できます)。
| `/アイテム 使用` |アイテムを使用して、そのコールバック機能をトリガーする |
| `/アイテム ドロップ` |現在のチャンネルにアイテムをドロップして他の人が拾えるようにする |
| `/アイテム 付与` |アイテムを別のユーザーにプレゼントする |

## 管理コマンド (/itemmod) 管理者

|コマンド |説明 |
| --- | --- |
| `/アイテム管理 付与` |指定したアイテムをユーザーに与える |
| `/アイテム管理 削除` |指定されたアイテムをユーザーから削除する |
| `/アイテム管理 一覧` |利用可能なすべてのアイテム (カスタムアイテムを含む) をリストします。
| `/アイテム管理 ユーザー一覧` |指定したユーザーが所有するアイテムを表示する |
| `/アイテム管理 カスタム追加` |カスタムサーバー項目を追加する |
| `/アイテム管理 カスタム削除` |カスタムサーバー項目を削除する |
| `/アイテム管理 カスタム編集` |カスタム アイテムのコンテンツ、価格設定、その他の設定を編集する |
| `/アイテム管理 カスタム一覧` |このサーバー内のすべてのカスタム項目をリストする |

## 落として拾う

> **オプションを削除:** `/アイテム ドロップ` は次のパラメータをサポートします。
> • **can_pickup** — 他の人がそれを拾えるかどうか (デフォルト: はい)
> • **pickup_duration** — ピックアップできる時間、1 ～ 86400 秒 (デフォルト: 60 秒)
> • **pickup_only_once** — 各ユーザーが 1 回だけピックアップできるかどうか (デフォルト: no)
> • **スコープ** — アイテムの抽出元のスコープ (サーバー / グローバル)

## カスタムアイテム

管理者は `/アイテム管理 カスタム追加` を使用してサーバー限定のアイテムを作成できます。カスタム アイテムが使用されると、そのプリセット テキスト コンテンツが送信されます。

`content` は、通常の変数、`if` 条件、`math`、埋め込みコマンド、`newmsg` / `edit` などを含む AutoReply テンプレート構文をサポートするようになりました。構文検証ルールも AutoReply に従います。テンプレート形式が無効な場合、追加または編集は完全にブロックされます。

|パラメータ |説明 |
| --- | --- |
| `name` |項目名 (最大 100 文字) |
| `content` |使用時に送信されるテキスト コンテンツ (最大 2000 文字、AutoReply 変数をサポート) |
| `description` |商品説明 (オプション) |
| `list_in_shop` |サーバーショップにアイテムを出品するかどうか |
| `price` |ショップ価格（出品時に必要、単位：サーバーコイン） |
| `remove_after_use` |アイテムが使用後に自動的に消費されるかどうか (デフォルト: はい) |
| `ephemeral_response` |使用後の応答がユーザー自身にのみ表示されるかどうか (デフォルト: いいえ) |

> **ヒント:** カスタム アイテムに価格とともに `list_in_shop = 是` が設定されている場合、そのアイテムは経済システムのサーバー ショップに表示され、他のユーザーが購入できるようになります。
