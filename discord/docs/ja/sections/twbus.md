# 🚌 twbus — 台湾バス / YouBike

台湾のバスのリアルタイムの到着状況、ルート概要、YouBike ステーションの状況を検索し、お気に入りの停留所をサポートします。バス データベースは 1 時間ごとに自動的に更新されます。

|コマンド |説明 |
| --- | --- |
| `/バス 路線検索` |指定したルートのすべての停留所と到着情報を検索する |
| `/バス 停留所検索` |ルート上の特定の停留所のリアルタイムの到着情報を検索する |
| `/バス ユーバイク` |指定した YouBike ステーションで利用可能な自転車とドックの数を調べます。
| `/バス お気に入り` |お気に入りの停留所や YouBike ステーションを表示してすぐにアクセス |

## インタラクティブボタン

クエリ結果の埋め込みには、その下にアクション ボタンが含まれています。

|ボタン |説明 |
| --- | --- |
| `🔄` |到着情報を更新 (10 秒のクールダウン) |
| `❤️` |お気に入りの追加/削除 (サーバーごとにお気に入りの制限を構成可能) |
| `🗺️` | Google マップで停留所の場所を開きます (座標が利用可能な場合) |

## 到着情報フィールド

|フィールド |説明 |
| --- | --- |
|到着予定日 |到着まであと数分。バスがすでに停留所に到着している場合は、「到着」と表示されます。
|到着予定 | API によって提供される推定時間 (HH:MM 形式) |
|車両ステータス |接近するバスのプレート番号と満席かどうかをリストします。
|停止シーケンス |ルートに沿ったこの停留所の順序 |
|座標 |クリックして Google マップを開きます |

## YouBike 情報フィールド

|フィールド |説明 |
| --- | --- |
|利用可能な自転車 |現在借りられる自転車の台数 |
|利用可能なドック |現在利用可能な空のドックの数 |
|ドックの合計 |ステーションの総容量 |
|ステータス |ステーションが正常に動作しているかどうか |
|最終更新日 | YouBike システムによって報告されるデータ更新時間 |

> **レート制限:** 各ユーザーは 10 秒に 1 回のみクエリを実行できます。更新ボタンにも同じ制限が適用されます。
> **お気に入りの制限:** デフォルトでは、各ユーザーは最大 2 つのお気に入りの停留所と 2 つのお気に入りの YouBike ステーションを持つことができます。この制限は構成によって調整できます。
