# 🚀 はじめに

ようこそ！開始するには、いくつかの簡単な手順を実行するだけです。

1. ホーム ページの **[ボットを招待]** ボタンをクリックして、ボットをサーバーに追加します
2. ボットが参加したら、`/情報 ヘルプ` を使用して、使用可能なすべてのコマンドを表示します
3. インタラクティブなチュートリアルには `/情報 チュートリアル` を使用します
4. [サーバーパネル](/panel/) に移動して詳細設定を行います。

> **ヒント:** ボットは、スラッシュ コマンド (`/コマンド`) と従来のプレフィックス コマンド (`y!command`) の両方をサポートします。

> **言語:** `/言語 設定` を使用して個人言語を選択するか、`/言語 サーバー` を使用してサーバーのデフォルトを設定します。ボットはデフォルトで繁体字中国語で応答します。
