# 🖼️ 貢献 — 貢献システム

ユーザーは Discord OAuth2 経由でログインして画像を送信できます。承認された投稿には、200 グローバル コインの報酬が与えられます。

|コマンド |説明 |
| --- | --- |
| `/contribute 草を与える` |グラスフェッド画像投稿ページを開く |
| `/contribute この人何言ってるの` | 「この人は何について話しているのか」の画像 (吹き出しが付いている種類) を送信する |
| `/contribute 動的ボイス` |ダイナミックな音声効果音を送信する |
