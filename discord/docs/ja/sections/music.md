# 🎵 音楽 — 音楽再生

Lavalink ノードを介した高品質の音楽再生。キュー管理、ループ再生 (トラック/キュー)、シャッフル、検索オートコンプリート、曲の推奨、切断時の自動離脱、キューの保存/復元、マルチノード フェイルオーバーのサポートを備えています。

|コマンド |説明 |
| --- | --- |
| `/音楽 再生` |音楽の再生 (URL またはキーワード検索をサポート) |
| `/音楽 検索` |音楽を検索 |
| `/音楽 スキップ` |現在のトラックをスキップ |
| `/音楽 シャッフル` |キューをシャッフルする |
| `/音楽 ループ` |ループモードの切り替え (トラック/キュー/オフ) |
| `/音楽 おすすめ` |おすすめの曲を入手 |
| `/音楽 キュー復元` |以前のキューを復元する |
| `/音楽 ノード` |利用可能な Lavalink ノードを表示 |
