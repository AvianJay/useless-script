# ✅ ServerWebVerify — Web 検証管理者

Web フォームを通じてサーバー メンバーを確認し、reCAPTCHA と Cloudflare Turnstile、デバイス フィンガープリント、IP ログ、地域アラート、その他のセキュリティ メカニズムをサポートします。新しいメンバーに認証を要求することができ、ボット アカウントの侵入を効果的に防止できます。

|コマンド |説明 |
| --- | --- |
| `/web認証 セットアップ` | Web 検証機能を構成する |
| `/web認証 強制認証` |指定したユーザーに検証を強制する |
| `/web認証 manual-verify` |ユーザーの検証を手動で渡す |
