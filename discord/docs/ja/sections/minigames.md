# 🃏 MiniGames — ミニゲーム エンターテイメント

サーバー コインとボットの世界通貨を賭けと支払いに使用するカード、ギャンブル、リアルタイム ゲームのコレクション。

Discord Explore ロビーから右側のカジノ ホストを介してグローバル カジノに入ることができます。 Explore 内の 9 つのカジノ ゲームはグローバル トークンを使用します。宝くじと `/games 宝くじ` のグローバル モードは同じ賞金プールと抽選ラウンドを共有します。

|コマンド |説明 |
| --- | --- |
| `/games ビッグ2` | Big Two — 古典的なカード ゲーム |
| `/games タワー` | Tower Climb — ギャンブル チャレンジ ゲーム |
| `/games スロット` |スロット — ペアとスリーカードのペイアウト |
| `/games ハイロー` | High-Low — 次のカードが高いか低いかを推測します。
| `/games ブラックジャック` |ブラックジャック — ヒット、スタンド、またはダブルダウンでディーラーと対決 |
| `/games ルーレット` |ルーレット — 赤/黒、奇数/偶数、高値/低値、または単一の数字に賭けます。
| `/games サイコロ` |サイコロ — 賭けて、ボタンで 1 ～ 6 の数字を選択します。
| `/games コインフリップ` |コインフリップ — 賭けをし、ボタンで表か裏を選びます |
| `/games スクラッチカード` |スクラッチ カード — 3x3 カードをスクラッチして、ランダムな賞品を明らかにします。
| `/games 宝くじ` |プログレッシブ宝くじ — 00 ～ 99 の番号を購入します。各ラウンドは次の 1 時間に引き継がれます。
| `/games doom` | Discord 内で DOOM をプレイする |
