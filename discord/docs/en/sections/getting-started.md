# 🚀 Getting Started

Welcome! You only need a few simple steps to get going:

1. Click the **"Invite the bot"** button on the home page to add the bot to your server
2. Once the bot has joined, use `/info help` to see all available commands
3. Use `/info tutorial` for an interactive tutorial
4. Head to the [server panel](/panel/) for advanced settings

> **Tip:** the bot supports both slash commands (`/command`) and classic prefix commands (`y!command`).

> **Language:** use `/language set` to choose your personal language, or `/language server` to set a default for your server. The bot replies in Traditional Chinese by default.
