# 🤖 AutoModerate — Auto Moderation 管理員自動化

A fully automated server protection system, including Anti-Spam, Anti-Raid, protection against spam from user-installed apps, invite link detection, scam traps, excessive emoji detection, punishment evasion detection, and various other automated moderation features.

| Command | Description |
| --- | --- |
| `/automod quick-setup` | Quickly configure auto-moderation rules |

> **Feature list:** Anti-Spam, Anti-Raid, Anti-UISpam, Anti-Invite Link, ScamTrap, excessive emoji detection, punishment evasion detection, AutoMod event integration. Anti-Invite Link supports an "allow this server's links" setting, letting you block only invites to external servers. Detailed configuration is available via the [web panel](/panel/).
