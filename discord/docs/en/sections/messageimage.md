# 📸 MessageImage — Message Screenshots

Turns Discord messages into some weird images(?). Supports the Upvoteboard feature: once a message receives enough upvotes, it's automatically screenshotted and sent to a designated channel to preserve the highlight.

| Command | Description |
| --- | --- |
| `y!ss` (reply to a message) | Screenshot the specified message |
| `Screenshot Generator` (message context menu) | Screenshot the specified message |
| `Terrible Make it a Quote` (message context menu) | Imitates the Make it a Quote image, but worse |
| `What is this guy talking about` (message context menu) | Screenshot the message and randomly add a speech-bubble image below it |
| `/upvoteboard` | Set the Upvoteboard channel |
