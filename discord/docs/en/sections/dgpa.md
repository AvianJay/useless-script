# 🏫 dgpa — Work/School Suspension Lookup

Scrapes work/school suspension announcements from the Directorate-General of Personnel Administration, Executive Yuan (DGPA) website. Supports setting up an auto-push channel so you get typhoon day notices the moment they're announced.

| Command | Description |
| --- | --- |
| `/nds` and related | Look up work/school suspensions and configure the push channel |
