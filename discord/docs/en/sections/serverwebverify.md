# ✅ ServerWebVerify — Web Verification 管理員

Verify server members through a web form, supporting reCAPTCHA and Cloudflare Turnstile, device fingerprinting, IP logging, region alerts, and other security mechanisms. New members can be required to verify, effectively preventing bot account intrusions.

| Command | Description |
| --- | --- |
| `/webverify setup` | Configure the web verification feature |
| `/webverify force-verify` | Force a specified user to verify |
| `/webverify manual-verify` | Manually pass a user's verification |
