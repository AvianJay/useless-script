# 🎵 Music — Music Playback

High-quality music playback through Lavalink nodes, with queue management, loop playback (track/queue), shuffle, search autocomplete, song recommendations, auto-leave on disconnect, queue save/restore, and multi-node failover support.

| Command | Description |
| --- | --- |
| `/music play` | Play music (supports a URL or keyword search) |
| `/music search` | Search for music |
| `/music skip` | Skip the current track |
| `/music shuffle` | Shuffle the queue |
| `/music loop` | Toggle loop mode (track/queue/off) |
| `/music recommend` | Get song recommendations |
| `/music restore-queue` | Restore a previous queue |
| `/music nodes` | View available Lavalink nodes |
