# 📌 StickyRole — Sticky Roles 管理員

Automatically restores a user's previously held roles when they leave and rejoin the server. Useful for remembering a member's verification status or special roles.

| Command | Description |
| --- | --- |
| `/stickyrole toggle` | Turn the sticky roles feature on or off |
| `/stickyrole add` | Add a role to the sticky list |
| `/stickyrole remove` | Remove a role from the sticky list |
