# 🖼️ Contribute — Contribution System

Users can log in via Discord OAuth2 to submit images. Approved submissions earn a reward of 200 global coins.

| Command | Description |
| --- | --- |
| `/contribute feedgrass` | Open the grass-fed image submission page |
| `/contribute what-is-this-guy-talking-about` | Submit a "what is this guy talking about" image (the kind with a speech bubble on it) |
| `/contribute dynamic-voice` | Submit a dynamic voice sound effect |
