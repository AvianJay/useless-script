# 🎭 FakeUser — Fake User 娛樂

Uses webhooks to impersonate other users' messages (for entertainment purposes), with a 30-second cooldown. Admins can configure a blacklist and a logging channel.

| Command | Description |
| --- | --- |
| `/fake` | Send a message as the specified user |
| `/fake-log-channel` | Set the logging channel |
| `/fake-blacklist` | Manage the blacklist |
