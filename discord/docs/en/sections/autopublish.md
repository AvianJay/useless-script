# 📢 AutoPublish — Auto Publish 管理員自動化

Once enabled, automatically publishes new messages in announcement channels, so you don't have to manually click "Publish". Includes a built-in rate limit of 10 messages per hour.

| Command | Description |
| --- | --- |
| `/autopublish view` | View the auto-publish configuration |
| `/autopublish settings` | Edit the auto-publish configuration |
