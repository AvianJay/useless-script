# 🃏 MiniGames — Mini Games 娛樂

A collection of card, gambling, and real-time games that use Server Coin and 全域幣 (the bot's global currency) for betting and payouts.

You can enter the global casino from the Discord Explore lobby via the casino host on the right side. The nine casino games inside Explore use 全域幣; the lottery and `/games lottery`'s global mode share the same prize pool and drawing rounds.

| Command | Description |
| --- | --- |
| `/games big2` | Big Two — a classic card game |
| `/games tower` | Tower Climb — a gambling challenge game |
| `/games slots` | Slots — payouts for pairs and three-of-a-kind |
| `/games highlow` | High-Low — guess whether the next card is higher or lower |
| `/games blackjack` | Blackjack — face off against the dealer with hit, stand, or double down |
| `/games roulette` | Roulette — bet on red/black, odd/even, high/low, or a single number |
| `/games dice` | Dice — place a bet, then pick a number from 1–6 with buttons |
| `/games coinflip` | Coin Flip — place a bet, then pick heads or tails with buttons |
| `/games scratchcard` | Scratch Card — scratch a 3x3 card to reveal a random prize |
| `/games lottery` | Progressive Lottery — buy numbers 00–99; each round draws on the next hour |
| `/games doom` | Play DOOM inside Discord |
