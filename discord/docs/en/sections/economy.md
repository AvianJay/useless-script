# 💰 Economy — Economy System

A full dual-currency virtual economy system. 全域幣 (the bot's global currency) works across servers, while Server Coin is limited to the current server. Includes daily/hourly rewards, shop buying and selling, transfers, an exchange rate mechanism, an inflation/deflation model, a check system, and more.

| Command | Description |
| --- | --- |
| `/economy daily` | Claim your daily reward |
| `/economy hourly` | Claim your hourly reward |
| `/economy balance` | Check your balance |
| `/economy buy` | Buy an item from the shop |
| `/economy sell` | Sell an item |
| `/economy trade` | Trade with / transfer to another user |
| `/economy history` | View transaction history |
| `/economymod` | Admin economy management tools |

> **Anti-abuse mechanism:** the system tracks currency injected by admins and enforces caps to keep the economy balanced.
