# 🔧 UtilCommands — Utility Commands

A collection of commonly used utility commands, including bot info, server info, latency testing, changelog, tutorials, and more.

| Command | Description |
| --- | --- |
| `/info help` | View all available commands |
| `/info bot` | View detailed bot information |
| `/info ping` | Test the bot's latency |
| `/info user` | View info for a specified user |
| `/info server` | View info for the current server |
| `/info avatar` | View a user's avatar |
| `/info banner` | View a user's banner |
| `/info mention` | Get a command's mention format |
| `/info changelog` | View the changelog |
| `/info commits` | View recent Git commit history |
| `/info tutorial` | Interactive getting-started tutorial |
| `/nitro` | Nitro gift link protection |
