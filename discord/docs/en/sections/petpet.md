# 🐾 petpet — PetPet Animation 娛樂

Generate a pat animation GIF from any user's avatar! Supports both slash commands and right-click context menu actions, and tracks pat and pat-received counts.

| Command | Description |
| --- | --- |
| `/petpet` | Generate a PetPet animation for a specified user |
| Right-click a user (long-press) → Apps → `PetPet` | Use the context menu directly on a user |
| `/petpet-stats` | View PetPet pat statistics |
