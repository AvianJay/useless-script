# 🔊 DynamicVoice — Dynamic Voice 管理員自動化

Automatically creates a dedicated temporary channel when a user joins a designated voice channel. Supports custom name templates (e.g. `{user} 的頻道`), and deletes the channel automatically once everyone leaves.

| Command | Description |
| --- | --- |
| `/dynamic-voice setup` | Set up dynamic voice channels |
| `/dynamic-voice disable` | Disable the dynamic voice feature |
| `/dynamic-voice play-audio` | Play a sound effect in the channel |
