# 📬 ModerationNotify — Moderation Notifications

Automatically sends a notification with an appeal channel when a user is kicked, banned, muted, or blacklisted. Admins can reply to appeals directly via buttons.

| Command | Description |
| --- | --- |
| `/user-appeal-channel` | Set the channel that receives appeals |
| `/user-appeal-blacklist` | Manage the appeal blacklist |
