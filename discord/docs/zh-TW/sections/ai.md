# 🤖 ai — AI 聊天

使用可選模型與 AI 對話，支援圖片、多輪對話、工具、個人長期記憶與伺服器共享背景。AI 會依實際用量扣除 **全域幣**，不是免費功能。

## 對話指令

| 指令 | 說明 |
| --- | --- |
| `/ai message [image] [new_conversation] [model]` | 與 AI 對話；可附圖、開始新對話或指定模型 |
| `/ai-clear` | 確認後清除目前伺服器／私訊範圍的對話歷史 |
| `/ai-history` | 私密顯示目前範圍最近 10 筆對話 |
| `/ai-memory view [query]` | 私密查看或搜尋自己的完整個人長期記憶；過長時以附件傳送 |
| `/ai-memory delete memory_id` | 經確認後刪除自己的一筆個人記憶 |
| `/ai-memory auto-summary [enabled] [global]` | 查看、開啟或關閉 30 分鐘閒置提煉；加 `global` 改設全域預設 |
| `/ai-memory auto-clear [enabled] [global]` | 查看、開啟或關閉 30 分鐘閒置自動清除對話；加 `global` 改設全域預設 |
| `/ai-set-default-model model` | 設定自己的跨伺服器預設文字模型 |
| `/ai-set-response-view container cost model` | 設定容器、計費資訊與模型資訊是否顯示 |
| `y!ai [模型] [訊息]` | 前綴版 AI 對話；開頭可放模型名稱 |
| `y!ai-new [訊息]` | 清除目前範圍的歷史並開始新對話 |
| `y!ai-clear` | 清除目前範圍的對話歷史 |
| `y!ai-history` | 查看目前範圍的對話歷史 |
| `y!ai-auto-summary [on|off] [global]` | 查看、開啟或關閉閒置提煉；加 `global` 改設全域預設 |
| `y!ai-auto-clear [on|off] [global]` | 查看、開啟或關閉閒置自動清除；加 `global` 改設全域預設 |

> `y!` 是預設前綴；若伺服器已變更前綴，請改用該伺服器目前的前綴。

AI 回覆可能會排成卡片、圖庫，或附上連結按鈕。需要你從幾個選項中挑一個時，AI 偶爾會附上追問按鈕或選單，點下去就會用你的身分把那段文字送給 AI 接續對話，照一般對話扣款。預設任何人都能點；AI 也可以限定只有原提問者能點。

## 全域知識庫與投稿

全域知識庫供所有使用者、伺服器與私訊共用；與個人、伺服器記憶分開儲存。每次 AI 請求會自動搜尋相關的已發布知識並帶入摘要，AI 也能主動搜尋或讀取全文。

| 指令 | 說明 |
| --- | --- |
| `/ai-knowledge search [query]` | 搜尋已審核通過的知識；未填關鍵字時顯示最近資料 |
| `/ai-knowledge submit title content [source_url] [knowledge_id] [expected_version]` | 投稿公開知識；修訂須附知識 ID 與目前版本，內容為完整替換稿 |
| `/ai-knowledge status submission_id` | 私密查看自己的投稿與審核結果；Bot 擁有者可查所有投稿 |
| `y!ai-knowledge [query]` | 前綴版知識搜尋 |
| `y!ai-knowledge submit "標題" 內容` | 前綴版投稿 |
| `y!ai-knowledge status submission_id` | 前綴版投稿狀態查詢 |
| `y!ai-config knowledge-channel #頻道` | 設定通知頻道；`off` 關閉 |
| `y!ai-knowledge remove knowledge_id` | Bot 擁有者下架知識，停止搜尋與自動帶入 |

- 使用既有 `ai_review_model` 自動審核，沿用 `y!ai-config review-model` 設定。投稿先進背景佇列，只有審核通過才會正式發布；拒絕、格式錯誤與服務失敗都不會發布。
- 單筆標題最多 80 字、內容最多 4,000 字，每人每小時最多 5 筆新投稿。相同投稿不會重複排隊；修訂有版本檢查，避免覆蓋審核期間的新內容。
- 審核失敗會自動重試最多 3 次；重啟後會恢復待審投稿。通知失敗會保留並重試，未設定頻道時可日後設定再補送。
- 管理員通知包含投稿 ID、結果、審核模型與說明；不會轉貼被拒絕或尚未審核的原文。未發布投稿只供投稿者與 Bot 擁有者查詢。
- AI 會主動使用、搜尋並整理各種記憶，不必說「記住」才保存明確、長期、低風險的資訊；也會主動投稿可公開重用的解法與通用經驗。私人資訊與伺服器限定資料維持原本的記憶範圍，不能轉進全域庫。刪除記憶仍需使用者明確要求。
- 自動審核未另收固定全域幣費用；正常 AI 對話仍依原本規則計費。審核結果是模型判斷，不保證事實完全正確，時效性資料仍需查證。

## 記憶與跨伺服器上下文

AI 使用三種不同的上下文，清除其中一種不會連帶清除其他資料：

| 類型 | 範圍與行為 |
| --- | --- |
| 對話歷史 | 依目前伺服器分開保存；私訊使用全域／DM 範圍。`/ai-clear` 與 `y!ai-clear` 只清除此範圍的對話歷史。 |
| `user_global` 個人記憶 | 綁定目前使用者，跨伺服器共用。AI 會自動帶入相關記憶，也可在使用者清楚表達穩定、低風險的偏好或個人事實時主動更新。 |
| `guild_shared` 伺服器記憶 | 只在目前伺服器共用，用於伺服器氛圍、共同偏好、常用清單或共同梗。每筆可分成 `members` 或 `admins` 寫入權限。 |

- `members` 共用記憶可由所有成員更新／刪除；`admins` 只有伺服器擁有者、管理員或具「管理伺服器」權限者可操作。普通成員只能建立 `members`，管理員可重新分級。舊有未標示權限的共用記憶視為 `members`。
- AI 可主動整理明確、耐久且低風險的個人或伺服器資訊。寫入前會優先沿用相同主題的 `memory_id` 合併，接近上限時先壓縮內容；只有確實不同的主題才新增。
- 單筆長期記憶最多 2,000 字、每個記憶空間最多 80 筆；空間已滿會拒絕新增，不會靜默擠掉舊資料。
- 系統會優先把與本次訊息相關、其次為最近更新的記憶放入模型上下文；未直接放入的內容仍可由 AI 記憶工具按需搜尋。
- 可以直接說「記住我偏好……」、「更新剛才的偏好……」或「忘記……」。刪除記憶一定要由使用者明確提出。
- 當使用者明確要求回想其他伺服器或全域／私訊中的既有 AI 對話時，AI 可按需搜尋，但只能讀取該名使用者自己的紀錄；其他伺服器的共享記憶不會被帶出。
- 請勿要求記住密碼、Token、API key、精準金流、身分證資料、醫療／法律隱私或其他高敏感資訊。
- 成員可寫的共用記憶會在模型上下文中標示為不可信資料，不會被當成系統指令。

## 30 分鐘閒置處理

閒置到期後可以「提煉成個人記憶再清除」或「只清除對話」，**兩者互斥、同時只能開啟一個**；開啟其中一個會自動關閉另一個。設定按「使用者＋目前伺服器／私訊」分開保存，預設兩者都關閉。

- 加上 `global` 會改設你的**全域預設**，並一併清除各場景的個別設定，讓所有伺服器與私訊都跟著這個預設走；之後若在某個場景單獨設定，該場景就改以自己的設定為準。
- 不帶 `enabled` 執行指令只會顯示狀態，包含目前生效值、設定來源（場景設定／全域預設／尚未設定）與全域預設值。

### 自動提煉

使用 `/ai-memory auto-summary true` 或 `y!ai-auto-summary on` 開啟後：

- 不會在開啟當下扣款。若目前已有完整成功問答，會從開啟時間重新計算 30 分鐘；之後每次成功 AI 回覆都會重新計時。
- 閒置到期時固定收取 **20 全域幣**，並使用該使用者目前的預設文字模型；不再依提煉輸入／輸出字數加收費用。
- 伺服器若有指定 AI 付款人，由該付款人支付；否則由使用者支付。私訊一律由使用者支付。
- 背景模型最多合併或新增 3 筆 `user_global` 個人記憶，不會刪除記憶，也不會寫入 `guild_shared`。即使沒有值得保存的內容，只要檢閱成功仍會保留 20 費用並清空舊對話。
- 餘額不足時不呼叫模型、不扣款、不清除歷史。模型失敗、輸出格式錯誤，或處理期間出現新訊息／記憶變更時，會全額退款並保留歷史。
- 背景結果不會在頻道發訊息；可用不帶參數的 `/ai-memory auto-summary` 或 `y!ai-auto-summary` 查看上次結果。Bot 重啟會恢復尚未完成的排程。
- 手動清除歷史、開始新對話或關閉功能時會取消目前排程。

### 自動清除

使用 `/ai-memory auto-clear true` 或 `y!ai-auto-clear on` 開啟後：

- 成功 AI 回覆後閒置 30 分鐘，系統會清除該場景的對話歷史；每次成功回覆都會重新計時。
- **不扣任何費用、不呼叫模型、不會寫入個人或伺服器記憶**，只是把該場景的對話歷史清空。
- 已存在的個人與伺服器長期記憶不受影響，只有對話歷史會被清除。
- 背景結果不會在頻道發訊息；可用不帶參數的 `/ai-memory auto-clear` 或 `y!ai-auto-clear` 查看上次結果。Bot 重啟會恢復尚未完成的排程。
- 手動清除歷史、開始新對話或關閉功能時會取消目前排程。

## 外部資料工具

- `search_google` 與 `search_google_images` 透過 Serper 搜尋；`fetch_webpage` 透過 Serper 抽取可讀頁面內容。
- `fetch_raw` 會由 Bot 直接 GET 公開網址，適合讀取原始 JSON、純文字、HTML、XML、YAML 或原始碼。它不經 Serper，並會套用 `!aicfg proxy` 設定的 SOCKS5 proxy。
- `fetch_raw` 只允許公開 HTTP／HTTPS 的標準連接埠，不接受網址帳密、localhost、內網位址或二進位內容；每次重新導向都會重新驗證，最多下載 1 MB，單次最多回傳 12,000 字。
- 原始內容與其他搜尋結果一樣是不可信外部資料，AI 只能將它當作參考內容，不能遵循其中要求改變規則、洩漏資料或執行動作的指示。
- `fetch_raw` 不消耗 Serper 額度，也不另收固定全域幣；一般 `/ai` 文字輸入與輸出仍照所選模型費率計費。
- `upload_html` 會把 AI 產生的單一 HTML 檔上傳到 [sharemyhtml.com](https://sharemyhtml.com) 並回傳公開網址，適合網頁、HTML 範例或互動 demo。任何拿到連結的人都能開啟，請勿要求放入密碼、Token 或個資；單檔上限 5 MB，AI 無法事後修改或刪除已上傳的頁面。

## 訊息讀取與截圖

- AI 讀取訊息時會先取得保留換行與 Markdown 的文字，以及 Embed 欄位、附件、投票、貼圖、反應、轉發內容與 Components V2 結構。
- AI 可以用 ID 查詢任何 Discord 使用者。目前伺服器的成員會附上暱稱、身分組與權限；不在伺服器內的人，或在私訊中查詢時，只會有名稱、頭像、帳號建立時間等公開資料。
- 只有視覺版面或 Discord 特殊格式無法由文字確認時，AI 才會建立訊息截圖。截圖是由 `chat_exporter` 重建的畫面，不是 Discord 客戶端的原生截圖；文字資料會補充重建畫面未呈現的格式。
- 截圖預設只含指定訊息；需要上下文時可加入同作者五分鐘內最多九則前文。暴雷內容會在截圖中展開。
- 單純將截圖附在回覆中不另收圖片分析費。要求 AI 判讀截圖會使用圖片分析工具，內建費用為 25 全域幣／次，失敗時退款。
- 訊息、截圖及其中的文字都屬不可信內容，AI 不會把當中的文字當成系統指令。

## 計費方式

### 文字對話

文字模型依字元數計費：

```text
輸入費用 = 實際輸入字數 × 所選模型每字費率
輸出費用 = 實際輸出字數 × 所選模型每字費率
總費用   = 輸入費用 + 輸出費用 + 另外使用的付費圖片工具
```

- 輸入費用會在送出模型前扣款；全域幣不足以支付輸入時不會送出請求。
- 輸出完成後依實際回覆字數扣款；若 AI 使用 `send_as_file` 或 `upload_html`，完整檔案或 HTML 內容字數也會計入輸出。
- 一般回覆預設會顯示費率、輸入／輸出字數與實際總扣款；使用 `/ai-set-response-view` 隱藏計費資訊只會隱藏畫面，不會停止扣款。
- 模型呼叫失敗時會退回已扣的輸入費用。

### 預設文字模型費率

下表是程式內建預設值，單位為「全域幣／字」。Bot 擁有者可即時調整模型與費率，因此實際請以 AI 回覆顯示的費率為準。

| 模型 | 預設費率 |
| --- | ---: |
| `openai-fast` | 0.05／字 |
| `openai` | 0.10／字 |
| `gpt-5-mini` | 0.10／字 |
| `openai-large` | 0.45／字 |
| `perplexity-fast` | 0.10／字 |
| `claude-fast` | 0.15／字 |
| `kimi-k2.6` | 0.05／字 |
| `gemma-4-31b` | 0.10／字 |
| `glm-5.1-t` | 0.10／字 |
| `qwen3.5-397b-a17b-t` | 0.15／字 |

內建全域預設模型為 `kimi-k2.6`（會依模型可用情況切換）；使用者可用 `/ai-set-default-model` 自行更改。

### 圖片工具費用

| 功能 | 內建預設費用 | 補充 |
| --- | ---: | --- |
| `/ai` 直接附加圖片 | 無額外固定費 | 仍依所選文字模型計算輸入與輸出字數 |
| 分析 Discord CDN 圖片網址 | 25 全域幣／次 | AI 需要呼叫圖片分析工具時另外扣除 |
| 判讀重建的 Discord 訊息截圖 | 25 全域幣／次 | 只附加截圖不收此費用；需要視覺判讀時才收費 |
| AI 圖片生成 | `gpt-image-2`：250 全域幣／張 | 依實際模型費率 × 要求張數；少交付會退回缺少張數的費用 |
| Google 圖片搜尋 | 無額外固定全域幣費用 | 一般文字輸入／輸出仍照所選模型計費；系統最多下載並審查 3 個候選，只附加一張通過審查的圖片 |
| AI 影片生成 | 目前停用 | 停用狀態不會進入扣款流程 |

付費圖片工具若執行失敗會退回該工具已扣費用。

### 參考圖生成與編輯

- 在 `/ai` 附圖並要求編輯或依照該圖生成，AI 可將目前附圖交給 `generate_image`；也可指定一個 Discord CDN 圖片網址。每次支援一張參考圖，會將圖片轉為 PNG 後呼叫 OpenAI 相容 Images API 的 `images.edit`；純文字生成仍使用 `images.generate`。
- `gpt-image-2` 預設標記為支援圖片輸入。新增其他圖片模型後，Bot 擁有者可用 `y!aicfg image-input-tag <model> on` 開啟，或以 `off` 關閉；請先確認目前 API 供應商的該模型支援圖片編輯端點。此標記與文字模型的 vision 標記分開管理。
- `y!aicfg image-models` 會以 `[image-input]` 顯示支援的模型。未標記模型、無效參考圖或下載失敗會在生成扣款前回報；生成失敗仍會退款，計費沿用每張圖片的模型費率。

### Google 圖片搜尋與安全性

- AI 可透過 Serper Images 搜尋公開圖片。由於該 endpoint 沒有 SafeSearch 選項，Bot 會依序下載最多 3 個候選並交給目前設定的 AI 審查模型；審查逾時、格式錯誤或無法確定時一律不顯示。
- 每次搜尋會消耗 Bot 擁有者的 Serper API 額度，候選審查也會產生審查模型的供應商用量；目前兩者都不另扣使用者固定全域幣，但 `/ai` 的一般文字輸入與輸出仍照所選模型費率計費。
- 通過的圖片會移除原始中繼資料、重新編碼為 PNG／JPEG，再作為 Discord 附件上傳。Bot 不會把任意外部圖片 URL 直接交給 Discord hotlink，因此能套用下載大小、像素、格式、重新導向與內網位址限制。
- 圖片審查仍可能誤判，且 Google Images 的搜尋結果不代表取得著作權授權。AI 應附上來源頁面；圖片只用於本次回覆，不建立長期快取。
- Bot 擁有者可用 `y!aicfg proxy socks5://host:1080` 設定圖片下載專用 SOCKS5 proxy、用 `y!aicfg proxy` 查看遮蔽後狀態，或用 `y!aicfg proxy clear` 清除。`sock5://` 會自動修正為 `socks5://`。
- Proxy 只套用於 Bot 自行下載的圖片與 `fetch_raw`，不會改變 Discord、OpenAI 相容 API 或 Serper API 的連線。若 URL 含帳密，狀態與回覆只會顯示遮蔽值。

## 提及與回覆模式

此功能預設關閉。具「管理伺服器」或「管理員」權限者可用下列指令設定：

| 指令 | 說明 |
| --- | --- |
| `/ai-admin mention-mode enabled` | 開啟或關閉本伺服器的提及與回覆觸發 |

- 直接提及時，Bot mention 必須是訊息第一個非空白內容；放在句中或句尾不會觸發。
- 回覆觸發時，必須回覆本功能啟用後由 AI 成功送出的暫存訊息，且該則 Discord 回覆必須保留提及 Bot；關閉「提及」的回覆不會觸發。
- 移除訊息開頭的 Bot mention 後必須仍有文字內容；只有 mention、空白或只有附件時不會回應。正常的 Bot 文字指令也不會被重複觸發。
- AI 回覆訊息 ID 只暫存在記憶體中，每個伺服器最多 200 筆、保留最長 24 小時；Bot 重啟或關閉此功能後會清除，因此重啟前的舊 AI 訊息不會觸發。
- 系統不以 Components V2 判斷 AI 訊息，因為其他功能也可能使用相同元件格式；只接受這個 AI 模組實際記錄的回覆訊息 ID。
- 提及與回覆會沿用 `y!ai` 的完整處理與計費流程，沒有額外固定費用；文字輸入／輸出仍按使用者的預設模型費率計費，若伺服器指定了付款人則由該付款人扣款。

## 伺服器付款人

預設由每位提出 AI 請求的使用者從自己的全域幣餘額付款。具「管理伺服器」或「管理員」權限者可將自己設為本伺服器的統一付款人；設定後，該伺服器內其他人的文字與付費圖片工具也會改扣指定付款人的全域幣。

| 指令 | 說明 |
| --- | --- |
| `/ai-admin billing set` | 將本伺服器 AI 付款人設為自己 |
| `/ai-admin billing view` | 查看目前付款方式／付款人 |
| `/ai-admin billing clear` | 清除指定付款人並恢復各自付款 |
| `y!ai-server-billing` | 查看目前付款方式／付款人 |
| `y!ai-server-billing set` | 將付款人設為自己 |
| `y!ai-server-billing clear` | 清除指定付款人 |

目前不能把其他成員指定為付款人；`set` 只會設定執行指令的管理員本人。

## 伺服器自訂 AI Prompt

管理員可提供伺服器背景、回覆風格或偏好，最多 1,800 字。這和 `guild_shared` 記憶不同：自訂 Prompt 是固定指示，伺服器記憶則是 AI 可搜尋與更新的長期資料。

| 指令 | 說明 |
| --- | --- |
| `/ai-admin prompt set prompt` | 設定伺服器自訂 AI Prompt |
| `/ai-admin prompt view` | 查看目前 Prompt |
| `/ai-admin prompt clear` | 清除目前 Prompt |
| `y!ai-server-prompt` | 查看目前 Prompt |
| `y!ai-server-prompt [內容]` | 設定 Prompt |
| `y!ai-server-prompt clear` | 清除 Prompt |

## 任務技能與檔案分析

AI 會按任務載入所需的操作說明與工具。目前包含瀏覽器、附來源的網路研究、Discord 對話考古、附件讀取、資料分析，以及 Meta Threads 文字發文。可以直接說「整理昨天的討論並附訊息連結」、「比較這幾個來源」，或「分析這份 CSV，附上清理後的檔案」。

- 可透過 `/ai` 的「檔案」選項、文字指令訊息的附件，或引用可見訊息中的附件提供文件。支援文字、CSV/TSV、JSON、PDF、DOCX 與 XLSX，單檔上限 8 MB。PDF 僅擷取文字，不含 OCR；試算表公式不會執行。
- 大型結果會暫存成可分段讀取的資源。JavaScript 變數與資源只保留於本次請求，完成、取消或逾時後清除。CSV、JSON 等文字結果可作為附件交付。
- 瀏覽器操作沿用 Discord 的允許／拒絕流程。Node 執行環境呼叫相同的瀏覽器與 Discord 權限檢查，無法直接存取主機檔案、機器人憑證或網路。
- Meta Threads 使用已設定 profile 的現有登入狀態，目前支援文字與連結，不支援媒體上傳。只有明確要求發佈時才會送出，並驗證結果、回傳貼文連結；要求草稿或測試技能不會發文。帳號互動限機器人擁有者及經擁有者開放的發文者。

### 擁有者的技能執行設定

在 bot 主機安裝更新後的 Python requirements，啟動 Linux Docker daemon，並先執行 `docker pull node:24-alpine`。Bot 不會自動拉取映像，也不會退回主機直接執行程式；沙箱不可用時，仍可使用原有瀏覽器工具與 Piston 執行工具。

- `!aicfg node-repl`：查看目前沙箱設定。
- `!aicfg node-repl on [image]`：以預先拉取且相容 Node 的映像啟用；`off` 關閉。
- `!aicfg browser-cdp <profile CDP URL>`：沿用現有方式設定瀏覽器。
- `!aicfg threads-publisher <Discord 使用者 ID> on`：開放該使用者操作 Threads 帳號；`off` 撤銷額外權限。機器人擁有者原本就有權限。

每個 kernel 均停用網路、使用唯讀檔案系統，只掛載一個唯讀 worker 程式，並採用非特權使用者及 CPU／記憶體／程序數限制。每個 bot 實例最多同時執行兩個 kernel。單次請求上限十分鐘、最多十二輪技能／工具操作，共用 48 次工具呼叫額度，包含 JavaScript 中的工具呼叫；請求結束後移除容器。
