# 変更履歴

## 0.24.1
* 日本語への完全対応を追加 | /言語
  * Discord のスラッシュコマンド名、パラメータ、返信、ボタン、メニューに加え、プレフィックスコマンド、サーバーパネル、公式サイト、ドキュメント、変更履歴を日本語で利用できるようになりました。自動モードでは Discord クライアントとブラウザの日本語設定も認識します。
  * AI は有効な言語に応じて、繁体字中国語、英語、日本語のいずれかを中心に返答するようになりました。ユーザーが別の言語を明示した場合はその指定を優先し、異なる言語の同時会話が互いに影響することもありません。
* サーバーの言語情報が渡されず、AntiBeast の AutoMod ルール作成または再同期に失敗する問題を修正しました。ブロックメッセージには、そのサーバーの有効な言語が使用されます。
* 関連ドキュメントと翻訳を更新しました。
* いくつかの不具合を修正しました。

## 0.24.0
* 繁体字中国語と英語の多言語対応を追加 | /言語
  * Discord のスラッシュコマンド名、パラメータ、返信、ボタン、メニューに加え、プレフィックスコマンド、サーバーパネル、公式サイト、ドキュメント、変更履歴を言語別に表示できるようになりました。
  * `/言語 設定` でサーバー共通の個人言語を設定でき、管理者は `/言語 サーバー` でサーバーの既定言語を設定できます。自動モードでは個人設定、サーバー設定、Discord クライアントの言語を順に参照し、`/言語 表示` で現在の判定結果を確認できます。
  * Web サイトに言語セレクターを追加しました。ログイン後は個人設定と同期し、未ログイン時は Web サイトのセッションとブラウザの言語に応じて表示言語を選びます。
* モデレーションシステムを更新 | /moderate
  * 処分通知のテンプレートとプレビューを追加しました。Markdown、Embed、表示項目、ケース番号の形式をカスタマイズでき、新しいケース番号を生成する際は通知チャンネルの本文や Embed から、ほかのボットが使用済みの番号を引き継げます。
  * サーバー独自のモデレーションアクションで `{1}` から `{9}` までのパラメータと既定値を利用できるようになりました。時間や理由などの入力を再利用でき、必須パラメータの不足、循環参照、展開後の上限超過は実行前に取り消されます。
* Web 認証を更新 | /web認証 関連id拒否
  * 既存の関連 ID をサーバーごとの拒否リストへ追加し、一致した際に実行するモデレーションアクションと報告チャンネルを設定できます。メンバーの認証時に一致すると、同じ関連アカウントも自動処理し、重複処分を避けるため成功結果を記録します。
  * 拒否リストの追加、削除、表示、無効化に対応しました。既存メンバーのスキャン結果を先に確認し、スキャンを開始した管理者が処分を承認することもできます。承認時には設定、メンバー状態、権限、ロール階層を再確認します。
* AI を更新 | /ai管理 プロンプト
  * サーバーごとのカスタムプロンプト上限を 1～6,000 文字の範囲で個別に調整できるようになりました。内容が長すぎる場合やコードブロックを含む場合、表示結果は UTF-8 テキストファイルで送信されます。
* リンク修正を更新 | /fixlink
  * Discord がリンクプレビューを生成した時点で処理を続行し、固定の待機時間が終わるまで待たないようにしました。更新イベントを受信できない場合もタイムアウト後に確認し、プレビューの取りこぼしを防ぎます。
* 関連ドキュメント、翻訳、クイック設定、Web パネルを更新しました。
* いくつかの不具合を修正しました。

## 0.23.0
* 固定メッセージを追加しました | /固定メッセージ
  * テキスト チャンネルまたはアナウンス チャンネルに最大 2,000 文字の固定メッセージを含めることができるようになりました。各チャンネルは 1 つに制限されており、各サーバーはデフォルトで最大 5 つを有効にできます。制限を超えた場合、どのエントリが保持されるかはリストの順序によって決まります。
  * チャンネルが新しいメッセージを受信すると、コンテンツは自動的に下部に再投稿されます。頻繁なスパムを回避するために、0 ～ 300 秒の沈黙期間と 5 ～ 3,600 秒の最小投稿間隔を設定できます。
  * チャンネルの追加、編集、削除、並べ替え、移動、手動投稿、およびメンション ポリシーをサポートします。自動投稿はデフォルトではメンションをトリガーしません。また、Discord API のレート制限によって引き起こされる失敗を減らすために、共有スロットルと再試行メカニズムが追加されました。
* 自動返信を更新しました
  * おはよう、こんにちは、こんばんは、一般的な挨拶の返信バリエーションを拡張しました。
  * `!weather <city name>` ミニコマンドを追加しました。これは、指定された都市の繁体字中国語の天気画像を取得します。都市が指定されていない場合は、使用方法が表示されます。
* 経済システムを更新
  * 転送、サーバー/グローバル通貨の通貨交換と転送、アイテムの取引、ショップの売買、小切手の換金、および予定された報酬はアトミック トランザクションになりました。いずれかのステップが失敗した場合は完全にロールバックされ、重複した控除、補助金、取引、報酬請求が防止されます。
  * 残高、在庫、供給、為替レート、決済結果の確認を追加しました。異常な為替レート、無効な値、または資産の不一致が検出されると、資産が変更される前に操作が中止され、ケースは所有者が確認して処理できるように通貨フローのブラックリストに自動的に追加されます。
* 関連ドキュメント、クイック セットアップ、Web パネルを更新しました。
* いくつかの不具合を修正しました。

## 0.22.4
* AI メンションおよび返信モードを更新 | /ai管理 メンションモード
  * ボットに直接言及する場合、その言及はメッセージ内の空白以外の最初の位置になければなりません。文の途中または最後に配置されたメンションは AI をトリガーしなくなり、通常のチャット中に偶発的にアクティブ化されることが減少しました。
  * AI メッセージに返信する場合、Discord Bot のメンションを保持する必要があり、現在のランタイム セッション中に AI によって記録されたメッセージのみに返信できます。返信の「メンション」オプションが無効になっている場合、これはトリガーされません。
* AI ツール呼び出しを更新
  * ネイティブ ツール呼び出しとシミュレートされたツール呼び出しは個別に解析されるようになりました。モデルがネイティブ モードをサポートしている場合、それが直接使用され、モデルが明示的にサポートしていない場合、またはシミュレート モードが構成されている場合にのみシミュレート モードにダウングレードされます。
  * シミュレートされたツール呼び出しには明示的な `tool_calls` 形式が必要になりました。通常の JSON 配列、ステータス設定、または `name` フィールドを含む通常の応答が、誤ってツールとして扱われて実行されることがなくなりました。
  * ツール実行中の進行状況テキストの解析と表示が改善されました。
* オーナーツールを更新 | y!eval
  * 複数行の Python、`await`、インポート、Discord コード ブロック、`print` 出力、および最後の行の式の結果をサポートします。 `_` を使用すると、その所有者の最後に成功した実行結果を取得できます。
  * 実行エラーは完全なトレースバックを返します。長すぎる出力、コード ブロックが含まれる出力、またはエラーが含まれる出力は、代わりに UTF-8 ファイルとして送信され、Discord のメンションはトリガーされません。
* AI 関連のドキュメントを更新しました。
* いくつかの不具合を修正しました。

## 0.22.3
* AI 外部データ ツールを更新
  * Google画像検索を追加しました。 AI は、必要に応じて人、場所、物体、その他の参照画像を検索し、最大 3 つの候補を検討し、安全性レビューに合格した 1 つの画像をソース ページとともに添付します。
  * 検索される画像は、ファイル サイズ、ピクセル寸法、形式、リダイレクト、内部ネットワーク アドレスによって制限されます。レビューに合格すると、元のメタデータが削除され、画像が再エンコードされてから、Discord の添付ファイルとしてアップロードされます。レビューがタイムアウトした場合、失敗した場合、または決定的でない場合は、何も表示されません。
  * Serper クォータを消費せずに、JSON、プレーン テキスト、HTML、XML、YAML、およびパブリック URL からソース コードを直接読み取ることができる `fetch_raw` ツールを追加しました。認証情報が埋め込まれた URL、ローカルホスト、内部ネットワーク アドレス、非標準ポート、バイナリ コンテンツをブロックし、ダウンロードと返されるサイズを制限します。
* AI メンションおよび返信モードを追加 | /ai管理 メンションモード
  * この機能はデフォルトでは無効になっています。サーバー管理者によって有効にされると、メンバーはボットに直接言及するか、AI によって正常に送信されたメッセージに返信して、`y!ai` を入力せずに AI をトリガーできます。
  * メンションまたは返信にはテキスト コンテンツが含まれている必要があり、既存の Bot コマンドが再トリガーされることはありません。応答は、完全な AI 処理パイプライン、デフォルト モデル、およびサーバーの支払者の請求設定に従います。
* 音楽を更新 | /音楽
  * ボットがシャットダウンすると、各サーバーの音声とテキスト チャンネル、現在の曲と再生の進行状況、キュー、音量、一時停止状態、ループ モード、ラジオが保存されます。再起動して Lavalink に再接続すると、再生セッションが自動的に復元されます。
  * 自動復元の前に、音声/ステージチャンネルの権限とメンバー制限がチェックされます。チャンネルが存在しない場合、権限が不十分である場合、または曲のロードまたは再生に失敗した場合は、後の再試行のために状態が保持され、その理由が利用可能なテキスト チャンネルで報告されます。
  * `/音楽 キュー復元` は、新しい再生状態形式と従来の URL キューの手動復元をサポートします。曲のエンコードの有効期限が切れている場合も、元の URL からの再読み込みが試行されます。
* AI 関連のドキュメント、翻訳、およびランタイム要件を更新しました。
* いくつかの不具合を修正しました。

## 0.21.10
* チケットシステムを追加 | /チケット
  * `/チケット セットアップ` クイック セットアップを追加しました。これにより、チケット カテゴリ、パネル チャンネル、サポート ロール、およびトランスクリプト ログ チャンネルを一度に指定でき、チケット パネルがすぐに公開されます。
  * ユーザーはパネルから件名と問題の説明を入力して、チケット開設者、サポート スタッフ、承認されたメンバーのみが閲覧できるプライベート テキスト チャンネルを作成できます。サポート スタッフによる申請、メンバーの追加または削除、サポート スタッフまたはチケット オープナーによる終了をサポートします。
  * 最大 10 個のカスタム チケット カテゴリをサポートし、それぞれに設定可能なボタン テキスト、絵文字、色、専用カテゴリ、追加のサポート ロール、ウェルカム メッセージが含まれます。公開されたパネルは、設定が変更されると自動的に更新されます。
  * チケットがクローズされると、オープナー、クレーマー、クローザー、理由、処理時間とともに HTML トランスクリプトがログ チャンネルに送信されます。 HTML の生成が失敗した場合は、代わりにプレーンテキストのトランスクリプトが使用され、Web サイト モジュールが有効になっている場合は Web 上で直接表示することもできます。
  * サーバー パネルには完全なチケット設定が含まれるようになり、カテゴリ権限の継承、サポートおよびブラックリストのロール、ユーザーごとの同時チケット制限、パネルの外観、ウェルカム メッセージ、およびチャンネル名のテンプレートを調整できるようになりました。
